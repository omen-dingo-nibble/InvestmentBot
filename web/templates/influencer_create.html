Create Influencer / Promoter Account

Influencer accounts look identical to normal user accounts but display a custom balance for screenshot / promotional use. The real balance is separate — they cannot withdraw the display amount.
Back to Users
How it works:
The portal shows the Display Balance (e.g. ₱10,000) to the user on every page — home, me, balance card, API. The actual balance field stays at ₱0 until real deposits are made. This lets promoters share screenshots showing a funded account without any financial risk. You can toggle or update the display balance at any time from the user detail page.
