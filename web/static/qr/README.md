# Payment QR Codes

Place your static payment QR code images here.

**Expected filenames** (configurable in Settings > Wallets):

| Crypto       | Default filename       |
|-------------|----------------------|
| BTC          | `btc_qr.png`         |
| ETH          | `eth_qr.png`         |
| USDT (TRC20) | `usdt_trc20_qr.png`  |
| USDT (ERC20) | `usdt_erc20_qr.png`  |
| LTC          | `ltc_qr.png`         |

You can also upload QR images directly from the web admin panel at:
**Settings & Wallets → Crypto Wallet Addresses & QR Codes**

The bot will automatically display the relevant QR image when a user
selects that currency during the deposit flow.
